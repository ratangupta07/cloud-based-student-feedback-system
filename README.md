# Cloud-Based Student Feedback System

A simple and responsive student feedback platform developed using HTML, CSS, JavaScript, and Python Flask. The system allows students to provide their academic experience, ratings, and suggestions through an easy-to-use interface.

## Technologies Used

- HTML
- CSS
- JavaScript
- Python Flask
- Render

## Cloud Deployment

Deployed on Render:

https://cloud-based-student-feedback-system.onrender.com

## Future Developments

Future improvements may include database integration, student authentication, an admin dashboard, feedback analytics, and secure cloud-based data storage.

## Project Status

Working prototype successfully deployed to the cloud.
